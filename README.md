# Network Anomaly Detection Project

The FastAPI app serves the original dataset/model tools, the chat security demo, and the live network security dashboard. For the controlled phone-to-laptop capture, GATv2, and temporary source-IP firewall workflow, follow [NETWORK_DEMO.md](NETWORK_DEMO.md).

Run automated checks with `python -m pytest -q`. The recovered GATv2 checkpoint, matching scalers, feature config, and threshold are restored under `models/`; `data/full_dataset.csv` is not required for live inference. See the demo guide for the current capture limitations and phone test steps.
